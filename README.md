# Web Scraping Examples

A collection of beginner-friendly web scraping examples using Python. The
project demonstrates three common approaches for collecting data from web
pages:

- **Requests and BeautifulSoup** - download HTML and parse it with CSS-like
  selectors.
- **Selenium** - automate a Chrome browser for JavaScript-rendered pages.
- **Scrapy** - crawl a website with a reusable spider and export structured
  data to JSON.

The examples use public weather-related pages for learning purposes. Always
respect a website's terms of service, robots.txt rules, and rate limits when
scraping.

## Project structure

```text
Requests and BeautifulSoup/
|-- Web_Scrapping_BeautifulSoup.ipynb
`-- web_scrapping.py
Scrapy/
|-- Web_Scrapping_Scrapy.ipynb
`-- OpenWeather_scraper/
    |-- headlines.json
    |-- scrapy.cfg
    `-- OpenWeather_scraper/
        |-- settings.py
        `-- spiders/OpenWeather_spider.py
Selenium/
`-- Web_Scrapping_Selenium.ipynb
```

## Setup

Use Python 3.10 or newer if possible. From the project root, create and
activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

If PowerShell prevents script activation, run the commands from an activated
Anaconda environment or use `.\.venv\Scripts\python.exe` directly.

## Running the examples

### Requests and BeautifulSoup

The notebook fetches the OpenWeather homepage and parses sample weather detail
HTML. Open and run:

```text
Requests and BeautifulSoup/Web_Scrapping_BeautifulSoup.ipynb
```

The accompanying `web_scrapping.py` file demonstrates Selenium-based extraction
of Karachi air-quality information.

### Selenium

Open and run:

```text
Selenium/Web_Scrapping_Selenium.ipynb
```

The notebook uses `webdriver-manager` to download/manage ChromeDriver. Google
Chrome must be installed. The browser may open visibly while the example runs.

### Scrapy

Run the spider from its project directory:

```powershell
cd "Scrapy\OpenWeather_scraper"
scrapy crawl OpenWeather_spider -O headlines.json
```

The spider reads headings from `https://openweathermap.org/` and exports up to
ten records with `No` and `Headline` fields. The project keeps
`ROBOTSTXT_OBEY = True` enabled.

## Notes

- Website layouts and selectors can change, so examples may need selector
  updates over time.
- Do not commit credentials, API keys, or private data.
- The included JSON file is sample output generated by the Scrapy spider.
